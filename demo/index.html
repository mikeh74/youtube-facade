🎬 YouTube Facade

A lightweight, accessible YouTube embed solution for faster page loads and better user experience.

YouTube Facade is a lightweight, accessible YouTube embed solution that provides a facade/placeholder for YouTube videos with minimal JavaScript. It improves page load performance by only loading the YouTube iframe when users interact with the video.

Benefits: Faster page loads, reduced data usage, improved privacy, and better user experience.

📖 How to Use

1. Include the Files via CDN


<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/foxshack/youtube-facade@1.0.0/dist/youtube-facade.css">
<script src="https://cdn.jsdelivr.net/gh/foxshack/youtube-facade@1.0.0/dist/youtube-facade.js"></script>

2. Add the HTML Markup

<a href="https://www.youtube.com/watch?v=VIDEO_ID" 
   class="youtube-facade"
   aria-label="Play embedded youtube video"
   target="_blank" 
   rel="noopener noreferrer">
  <img src="https://i.ytimg.com/vi/VIDEO_ID/maxresdefault.jpg" 
       class="youtube-facade-img"
       alt="Video thumbnail">
  <div class="youtube-facade-playbtn"></div>
</a>

3. Initialize the Library

<script>
  youtubeFacade({ muteForAutoplay: true });
</script>

📋 Available Attributes

  • class="youtube-facade" - Required: Identifies the facade element
  • data-youtube-modal="true" - Optional: Opens video in a modal
  • data-use-youtube-api - Optional: Use YouTube Player API for advanced controls
  • data-target="#element-id" - Optional: Place video in a specific target element
  • data-youtube-id="VIDEO_ID" - Optional: Specify video ID instead of href
  • data-use-youtube-thumb - Optional: Auto-load thumbnail from YouTube
  • data-title="Video Title" - Optional: Set iframe title for accessibility

⚠️ Safari Compatibility Note:

When using data-target with Safari, if your target is an <img> element with a source from i.ytimg.com, the replacement may not work correctly. Use a <div> wrapper around the image instead to ensure compatibility across all browsers.
